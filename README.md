# Quote the instruction

Preprint: [paper.md](paper.md).

Small language models fine-tuned on step-by-step solutions often fail on problems that contain an instruction they
never saw in training: the model drops the unfamiliar step or replaces it with a familiar one. Writing each instruction into the step that carries it out ("Step 2 ('Square it'): 23 x 23 =
529") raised accuracy on held-out problems from 0.63 to 0.91 for Qwen2.5-1.5B and from 0.07 to 0.48 for SmolLM-1.7B.
Each experiment's predictions and scoring were committed before it ran.

Pre-registrations, scoring code, result files and raw replies are available on request: futurisminstitute@gmail.com.
